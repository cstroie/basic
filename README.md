# BASIC Interpreter

A simple text-based interpreter for classic 8-bit BASIC running entirely in the browser.

## Features

- Basic command set including PRINT, INPUT, LET, GOTO, IF, THEN, FOR, TO, STEP, NEXT, REM, END.
- Support for loading and saving programs to/from localStorage.
- Simple FOR and NEXT loops with basic conditionals.
- Basic error handling and syntax checking.

## Usage

1. Open `index.html` directly in a web browser to start the interpreter.

2. Type BASIC commands in the input field and press Enter to execute them.

3. Use the on-screen keyboard or physical keyboard to interact with the interpreter.

4. Save your programs using the "SAVE" button or command and load them using the "LOAD" button or command.

Note: This interpreter runs entirely in your browser and does not require a server or Python installation.
